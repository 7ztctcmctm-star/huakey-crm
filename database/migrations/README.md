# 数据库迁移说明

本目录存放铧旗 CRM 的 MySQL 8.0 数据库迁移脚本。

## 命名规范

- `XXX_description.sql`：正向迁移脚本
- `XXX_description_down.sql`：对应的回滚脚本
- 编号采用三位数字，按字典序执行

## 迁移编号说明

当前迁移文件列表存在以下编号空缺，均为有意跳过：

| 编号 | 状态 | 原因 |
|------|------|------|
| 064  | 跳过 | [待补充：请项目负责人填写具体原因] |
| 065  | 跳过 | [待补充：请项目负责人填写具体原因] |

> 新迁移请从当前最大编号（098）之后顺序递增。严禁填补历史空缺编号，以免与已部署环境的 `schema_migrations` 表记录冲突。

## 执行方式

迁移由 `database/run_migrations.js` 在应用容器启动时自动执行。脚本会按文件名字典序依次运行，并在 `schema_migrations` 表中记录已执行的版本。
