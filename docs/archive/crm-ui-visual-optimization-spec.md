# 铧旗CRM 视觉优化规范

> **目标**：在现有 Apple Design System 基础上，进一步统一视觉语言、提升界面质感，打造高端、专业、可信赖的 B2B SaaS 体验。
> **适用范围**：`frontend/src` 下所有 Vue 组件与样式文件。
> **生效主题**：以 `frontend/src/styles/apple.css` 为唯一主题源，逐步下线 `frontend/src/assets/styles/theme.css`。

---

## 一、设计原则

1. **克制即高级**  
   少用大色块、少用高饱和色、少用装饰性元素。让数据和内容成为主角，设计退后。

2. **秩序感优先**  
   统一的 8pt 栅格、一致的组件尺寸、清晰的信息层级，让用户一眼找到重点。

3. **细节决定质感**  
   圆角、阴影、过渡、hover 状态必须成体系，禁止同一类组件出现多种样式。

4. **反馈要轻柔**  
   所有交互反馈使用缓动曲线 `cubic-bezier(0.25, 0.1, 0.25, 1)`，时长 0.2s–0.3s，避免生硬跳变。

## 二、色彩系统

### 2.1 主色与强调色

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-primary` | `#1d1d1f` | 主文本、标题、侧边栏选中文字 |
| `--color-accent` | `#0071e3` | 主按钮、链接、Tab 下划线、悬停边框 |
| `--color-accent-hover` | `#0077ed` | 主按钮悬停 |
| `--color-accent-active` | `#006edb` | 主按钮按下 |
| `--color-accent-bg` | `rgba(0, 113, 227, 0.08)` | 输入框聚焦光晕、次要背景 |

### 2.2 语义色（降饱和处理）

| 语义 | 色值 | 背景色 | 用途 |
|------|------|--------|------|
| 成功 | `#2aa85c` | `rgba(42, 168, 92, 0.08)` | 已成交、已通过、正向趋势 |
| 警告 | `#d97706` | `rgba(217, 119, 6, 0.08)` | 即将过期、待处理 |
| 危险 | `#dc2626` | `rgba(220, 38, 38, 0.08)` | 逾期、失败、删除 |
| 信息 | `#0071e3` | `rgba(0, 113, 227, 0.08)` | 提示、进行中 |

> 旧版 success `#30d158`、warning `#ff9f0a`、danger `#ff453a` 过于鲜艳，在 B2B 场景里显得轻浮，统一替换为上方降饱和色值。

### 2.3 中性色

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-text` | `#1d1d1f` | 正文、标题 |
| `--color-text-secondary` | `#6e6e73` | 次要说明、表头 |
| `--color-text-tertiary` | `#86868b` | 占位符、禁用态 |
| `--color-bg` | `#ffffff` | 卡片、弹窗、输入框背景 |
| `--color-bg-secondary` | `#f5f5f7` | 页面背景 |
| `--color-bg-tertiary` | `#fbfbfd` | 表头、侧边栏背景 |
| `--color-border` | `rgba(0, 0, 0, 0.06)` | 卡片边框、分割线 |
| `--color-border-strong` | `rgba(0, 0, 0, 0.1)` | 输入框边框、表头底部分割 |

### 2.4 使用约束

- 禁止在组件里写死色值，所有颜色必须从 CSS 变量读取。
- 状态色不得用于大面积背景，只能用于 Tag、Badge、Alert、Icon、小指示点。
- 文字链、文字按钮统一使用 `--color-accent`，禁用默认蓝色。

## 三、字体与排版

### 3.1 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'SF Pro Text',
             'Helvetica Neue', 'PingFang SC', 'Microsoft YaHei', Arial, sans-serif;
```

### 3.2 字号与字重

| 层级 | 字号 | 字重 | 字间距 | 行高 | 用途 |
|------|------|------|--------|------|------|
| 页面标题 H1 | 28px | 600 | -0.02em | 1.2 | Dashboard / 列表页大标题 |
| 区块标题 H2 | 20px | 600 | -0.02em | 1.3 | 卡片标题、弹窗标题 |
| 卡片内标题 H3 | 17px | 600 | -0.01em | 1.4 | 详情页分组标题 |
| 正文 | 14px | 400 | -0.01em | 1.5 | 表格内容、表单说明 |
| 辅助文字 | 13px | 400 | 0 | 1.5 | 标签、时间、描述 |
| 表头 / 徽章 | 12px | 500 | 0.02em | 1.4 | 表格表头（大写）、Tag |
| 大数字 | 40px | 700 | -0.03em | 1.1 | 统计卡片关键数值 |
| 中数字 | 28px | 700 | -0.02em | 1.1 | 次级统计数值 |

### 3.3 排版规则

- 页面标题与正文之间保持 24px 间距。
- 表头文字统一 `text-transform: uppercase; letter-spacing: 0.02em;`，营造秩序感。
- 金额、转化率、赢单率等大数字优先使用 tabular-nums，避免数字跳动：
  ```css
  font-variant-numeric: tabular-nums;
  ```
- 正文段落最大宽度控制在 640px，避免阅读疲劳。

## 四、间距系统

沿用 8pt 栅格，最小单位 4px。

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-1` | 4px | 图标与文字间距、紧凑内边距 |
| `--space-2` | 8px | 行内元素间距、小按钮内边距 |
| `--space-3` | 12px | 表单行间距、卡片内部小间距 |
| `--space-4` | 16px | 卡片内边距基础值 |
| `--space-5` | 24px | 页面内边距、卡片之间间距 |
| `--space-6` | 32px | 大卡片内边距、弹窗内边距 |
| `--space-7` | 48px | 页面区块间距 |
| `--space-8` | 64px | 大模块间距 |

### 使用约束

- 禁止出现 5px、7px、13px、18px 等破坏栅格的值。
- 卡片与卡片之间统一 24px，卡片内部标题区与内容区统一 24px/32px。
- 表单 `el-form-item` 下边距统一 16px，搜索卡片的表单项下边距可压缩至 12px。

## 五、圆角与阴影

### 5.1 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 8px | 按钮、输入框、小标签、表格 |
| `--radius-md` | 12px | 下拉菜单、选择器面板、日期面板 |
| `--radius-lg` | 16px | 卡片 |
| `--radius-xl` | 20px | 弹窗、消息框 |
| `--radius-pill` | 999px | Tag、胶囊按钮、状态点 |

### 5.2 阴影

| Token | 值 | 用途 |
|-------|-----|------|
| `--shadow-sm` | `0 1px 3px rgba(0,0,0,0.04)` | 卡片默认阴影 |
| `--shadow-md` | `0 2px 12px rgba(0,0,0,0.08)` | 卡片悬停、下拉菜单 |
| `--shadow-lg` | `0 8px 30px rgba(0,0,0,0.12)` | 弹窗、Popover、日期面板 |

### 使用约束

- 卡片必须有 `shadow-sm`，悬停时过渡到 `shadow-md`。
- 弹窗必须有 `shadow-lg`，禁止只用边框无阴影。
- 输入框聚焦时加 `0 0 0 3px var(--color-accent-bg)` 光晕，不使用默认蓝色外发光。

## 六、布局规范

### 6.1 页面结构

```
┌─────────────────────────────────────┐
│ Header（52px，毛玻璃，底部 1px 分割线） │
├──────────┬──────────────────────────┤
│          │  Page Header（标题 + 操作） │
│ Sidebar  │  ─────────────────────────  │
│（浅色）   │  Filter Card              │
│          │  ─────────────────────────  │
│          │  Data Card / Table        │
│          │  ─────────────────────────  │
│          │  Pagination               │
└──────────┴──────────────────────────┘
```

### 6.2 侧边栏

- 背景：`#ffffff`，右边框 `rgba(0,0,0,0.06)`。
- 菜单项高度 36px，圆角 8px，选中态背景 `#f5f5f7`、文字 `#1d1d1f`、字重 600。
- 不要回到深色侧边栏，浅色更现代、更高级。

### 6.3 顶栏

- 高度 52px，背景 `rgba(255,255,255,0.72)`， backdrop-filter 毛玻璃。
- 底部 1px 分割线 `rgba(0,0,0,0.06)`。
- 搜索、通知、用户头像右对齐，头像尺寸 32px。

### 6.4 内容区

- 页面背景 `#f5f5f7`。
- 内容区内边距 24px（桌面）、16px（移动端）。
- 页面最大宽度：无限制时默认撑满，但核心表单建议 max-width 960px 居中。

## 七、组件规范

### 7.1 按钮

| 类型 | 背景 | 边框 | 文字 | 悬停 |
|------|------|------|------|------|
| Primary | `--color-accent` | `--color-accent` | `#fff` | `--color-accent-hover` |
| Default | `#fff` | `--color-border-strong` | `--color-text` | 边框变 accent，背景加 accent-bg |
| Danger | `--color-danger` | `--color-danger` | `#fff` | 加深 8% |
| Link | transparent | none | `--color-accent` | `--color-accent-hover` |

- 默认高度 36px，大按钮 44px，小按钮 28px。
- 圆角 8px，左右内边距 24px。
- 按钮图标与文字间距 8px。

### 7.2 卡片

- 圆角 16px，背景 `#fff`，边框 `1px solid var(--color-border)`，阴影 `shadow-sm`。
- 卡片头部：内边距 16px 32px，底部 1px 分割线，标题 17px / 600。
- 卡片内容：内边距 32px。
- 悬停：阴影过渡到 `shadow-md`，上移 2px（仅可点击卡片）。

### 7.3 统计卡片

- 禁止放置大图标，数字是主角。
- 关键数字 40px / 700 / `-0.03em`。
- 标签 13px / 500 / `--color-text-secondary`。
- 趋势文字 12px / 600，正增长用 success，负增长用 danger。
- 悬停：上移 2px + 阴影加深。

### 7.4 表格

- 圆角 16px，表头背景 `#ffffff`，表头文字 12px / 500 / 大写 / `--color-text-secondary`。
- 表头底部 1px 实色分割线 `--color-border-strong`。
- 行高 56px，行底部 1px 分割线 `--color-border`。
- 行悬停背景 `#f5f5f7`。
- 逾期/高风险行左侧 3px 色条警示，不整行变红。
- 操作列最多保留 2 个高频按钮，其余收入“更多”下拉菜单。
- 表格空状态使用插画 + 14px 灰色说明，不要只有 “No Data”。

### 7.5 表单与输入框

- 输入框高度 36px，圆角 8px，边框 `--color-border-strong`。
- 聚焦：边框变 accent，外加 3px accent-bg 光晕。
- 标签 13px / 500 / `--color-text-secondary`。
- 表单项间距 16px。
- 必填项用红色星号，放在标签右侧，不加大字号。

### 7.6 Tag / 徽章

- 统一胶囊形状（`radius-pill`），高度 24px，左右内边距 12px。
- 背景用对应语义色的 8% 透明度，文字用对应语义色。
- 禁止使用实心高饱和 Tag。

### 7.7 弹窗与抽屉

- 弹窗圆角 20px，无边框，阴影 `shadow-lg`。
- 头部内边距 24px 32px，标题 17px / 600，关闭按钮 24px × 24px。
- 内容区内边距 32px，底部操作区 16px 32px，顶部 1px 分割线。
- 抽屉宽度默认 560px，关键详情可 720px，不宜更宽。
- 弹窗/抽屉进入动画：scale 0.95 → 1 + opacity 0 → 1，时长 0.25s。

### 7.8 分页

- 页码按钮 32px × 32px，圆角 8px。
- 选中态背景 accent，文字白色。
- 悬停态背景 `#f5f5f7`。
- 与表格间距 24px，右对齐。

## 八、动效与微交互

### 8.1 缓动与时长

- 默认缓动：`cubic-bezier(0.25, 0.1, 0.25, 1)`。
- 悬停：0.2s。
- 页面/弹窗进入：0.25s–0.3s。
- 数字变化：0.6s–0.8s。

### 8.2 页面切换

- 使用 `fade-slide`：从下方 12px 淡入，时长 0.3s。
- 避免突然白屏或硬切。

### 8.3 数字动画

- 统计卡片数值变化时使用计数动画（count-up），时长 600ms。
- 已提供 `useCountUp.js` composable，建议在所有 Dashboard 统计卡片中接入。

### 8.4 加载状态

- 表格加载使用骨架屏（Skeleton），不要全屏转圈。
- 按钮 loading 使用 Element Plus 自带 spinner，尺寸 16px。
- 全局加载蒙层背景 `rgba(255,255,255,0.72)` + 8px 毛玻璃。

### 8.5 Hover / Focus 状态清单

| 元素 | Hover | Focus / Active |
|------|-------|----------------|
| 卡片 | shadow-md + translateY(-2px) | — |
| 按钮 Primary | 背景变浅 | 背景变深 |
| 按钮 Default | 边框变 accent，背景加 accent-bg | — |
| 输入框 | 边框变深 | 边框变 accent + 光晕 |
| 表格行 | 背景变 #f5f5f7 | — |
| 链接 | 颜色变 accent-hover | — |
| 菜单项 | 背景变 #f5f5f7 | 背景变 #f5f5f7，字重 600 |

## 九、关键页面改造要点

### 9.1 Dashboard

- 统计卡片一行 4 列（桌面），2 列（平板），1 列（手机）。
- 数字 40px 居左，标签在数字下方。
- 图表卡片与列表卡片间距 24px。
- 图表颜色从语义色系统取，禁用默认彩虹色。

### 9.2 客户 / 商机 / 报价 / 合同列表

- 搜索筛选区做成独立卡片，圆角 16px，内部表单紧凑排列。
- 表格卡片紧随其下，内部 padding 0（表格自身带圆角）。
- 操作列收敛按钮，按业务优先级：
  - 客户列表：查看、编辑、更多（分配、删除）
  - 商机列表：查看、推进、更多（编辑、创建报价、删除）
  - 报价列表：查看、编辑、更多（发送、提交审批、转合同、删除）
  - 合同列表：查看、回款、更多（编辑、提交审批、删除）

### 9.3 详情页

- 采用“左侧主信息 + 右侧关联信息”两栏布局（桌面），移动端堆叠。
- 基本信息用 17px 分组标题，组内字段两列或三列布局。
- 时间线、跟进记录等长列表用卡片包裹，内部无边框列表。
- 关键操作（创建报价、创建合同、回款）放在页面右上角，使用 Primary 按钮。

## 十一、禁止事项

1. 禁止在组件内写死颜色、字号、间距。
2. 禁止深色侧边栏回退。
3. 禁止表格操作列超过 2 个可见按钮。
4. 禁止使用高饱和状态色作为大面积背景。
5. 禁止同一页面出现多种圆角或阴影风格。
6. 禁止无意义的动画（如页面元素持续浮动、背景闪烁）。
