## 5. 后续安全建议

| 优先级 | 建议 | 说明 |
|--------|------|------|
| 高 | 部署 HTTPS | 当前 HTTP 明文传输，密码可被嗅探 |
| 高 | 删除 .env.bak 备份 | 含密码明文的备份文件需删除 |
| 中 | 配置自动备份 | 当前无定时数据库备份 |
| 中 | 配置监控告警 | 服务异常时无通知机制 |
| 低 | 定期改密 | 建议每 90 天修改管理员密码 |
