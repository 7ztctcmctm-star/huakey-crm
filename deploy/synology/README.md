# 铧旗CRM系统 — 群晖NAS部署指南

> 本指南面向没有运维经验的用户，每一步都告诉你在哪里点击。
> 预计用时：30-40 分钟（大部分时间是等待自动构建）

---

## 部署前检查

在开始之前，确认你的群晖满足以下条件：

| 检查项 | 怎么看 | 要求 |
|--------|--------|------|
| DSM 版本 | 群晖桌面 → 右上角 **?** → **关于 Synology DSM** | **7.2 或更高** |
| 内存 | 群晖桌面 → **存储管理器** → **概述** | **2GB 以上**（推荐 4GB） |
| 可用空间 | 群晖桌面 → **存储管理器** → **存储池** | **5GB 以上** |
| Container Manager | 群晖桌面 → **主菜单** → 看有没有 "Container Manager" | 需要已安装 |
| 群晖 IP 地址 | 群晖桌面 → **主菜单** → **控制面板** → **网络** → **网络界面** | 记住这个 IP |

### 如果没有 Container Manager

1. 打开群晖桌面的 **"套件中心"**（Package Center）
2. 在搜索框输入 **"Container Manager"**
3. 点击 **"安装"**
4. 等待安装完成

> 旧版 DSM（7.0以下）可能叫 "Docker"，功能一样。

## 第一步：上传项目到群晖

### 1.1 需要上传的文件

在你的电脑上，项目文件夹 `c:\huakey-crm` 里，需要上传以下内容：

**必须上传的文件夹：**
- `backend/` — 后端程序
- `frontend/` — 前端页面
- `database/` — 数据库脚本

**必须上传的文件（在项目根目录下）：**
- `Dockerfile.synology` — Docker 构建配置
- `docker-compose.synology.yml` — Docker 启动配置
- `init-complete.sql` — 数据库初始化脚本

**不需要上传的（跳过这些）：**
- `node_modules/`
- `.git/`
- `.vercel/`
- `deploy_package/`
- `*.tar.gz`

### 1.2 上传方法

**方法 A：File Station（群晖自带，推荐）**

1. 浏览器打开 `http://你的群晖IP:5000`
2. 登录群晖管理员账号
3. 打开 **"File Station"**（文件管理器）
4. 左侧选择一个共享文件夹（比如 `homes` 或 `web`）
5. 点击上方 **"新建"** → **"新建文件夹"** → 输入 `huakey-crm`
6. 双击进入 `huakey-crm` 文件夹
7. 点击上方 **"上传"** → **"上传 - 跳过同名文件"**
8. 选择电脑上的项目文件 → 等待上传

**方法 B：Windows 网络共享（文件多时更快）**

1. Windows 文件管理器地址栏输入 `\\你的群晖IP`
2. 输入群晖账号密码
3. 打开一个共享文件夹
4. 新建 `huakey-crm` 文件夹
5. 把项目文件直接拖进去

### 1.3 确认上传结果

上传完成后，群晖上的 `huakey-crm` 文件夹应该包含：

```
huakey-crm/
├── backend/
├── frontend/
├── database/
├── Dockerfile.synology
├── docker-compose.synology.yml
├── init-complete.sql
└── ...其他文件
```

## 第二步：创建环境配置文件

这一步告诉系统数据库密码是多少。

### 2.1 创建 .env 文件

1. 在 File Station 中，进入 `huakey-crm` 文件夹
2. 点击上方 **"新建"** → **"新建文件"**
3. 文件名输入：`.env`（注意有个点在前面）
4. 点击 **"确定"**
5. **双击** 打开 `.env` 文件（会用群晖自带的文本编辑器打开）
6. 把下面的内容**完整复制粘贴**进去：

```
# === 数据库配置 ===
# root 密码（管理用，自己设一个强密码）
MYSQL_ROOT_PASSWORD=MyRoot@2024

# 普通用户密码（系统连接数据库用，自己设一个）
MYSQL_PASSWORD=MyCrm@2024

# === 安全配置 ===
# JWT 密钥（随便打一串字符，越长越好，不要和别人共享）
JWT_SECRET=abc123def456ghi789jkl012mno345pqr678stu901
```

### 2.2 修改密码（重要！）

把上面三个值改成你自己的：

| 变量 | 改成什么 | 示例 |
|------|----------|------|
| `MYSQL_ROOT_PASSWORD` | 数据库管理员密码 | `MyCompany@2024` |
| `MYSQL_PASSWORD` | 数据库用户密码 | `CrmDb@2024` |
| `JWT_SECRET` | 一串随机字符（30位以上） | 随便按键盘打一串 |

> **记好这三个密码！** 以后可能用到。

### 2.3 保存文件

1. 按 `Ctrl + S` 保存
2. 关闭编辑器

## 第三步：用 Container Manager 部署

### 3.1 打开 Container Manager

1. 群晖桌面 → 左上角 **"主菜单"**（四个小方块图标）
2. 点击 **"Container Manager"**

### 3.2 新建项目

1. 左侧菜单点击 **"项目"**（Projects）
2. 点击右上角 **"新建"**（Create）
3. 填写以下信息：

| 字段 | 填什么 |
|------|--------|
| 项目名称 | `huakey-crm` |
| 路径 | 选择你上传项目的那个 `huakey-crm` 文件夹 |

4. **"来源"** 选择：**"设置路径"**（Set path）
5. 路径选择 `huakey-crm/docker-compose.synology.yml`
6. 点击 **"下一步"**

### 3.3 环境变量（如果弹出）

如果弹出环境变量设置界面，直接点 **"下一步"** 跳过（.env 文件会自动读取）。

### 3.4 开始构建

1. 点击 **"完成"** 或 **"下一步"**
2. 系统开始自动执行：
   - ✅ 下载 MySQL 镜像（约 200MB，2-5 分钟）
   - ✅ 下载 Node.js 镜像（约 180MB，2-5 分钟）
   - ✅ 构建 CRM 应用（编译前端代码，5-10 分钟）
   - ✅ 启动数据库容器
   - ✅ 启动应用容器

3. **耐心等待 10-15 分钟**，不要关闭页面

### 3.5 检查是否成功

1. 左侧菜单点击 **"容器"**（Container）
2. 应该看到两个容器，都是 **绿色** 状态：

| 容器名 | 状态 | 说明 |
|--------|------|------|
| `huakey-mysql` | 🟢 运行中 | 数据库 |
| `huakey-app` | 🟢 运行中 | CRM 应用 |

3. 如果是 🔴 红色，看下面的"故障排除"。

## 第四步：访问 CRM 系统

### 4.1 打开浏览器

在浏览器地址栏输入：

```
http://你的群晖IP:5000
```

例如：`http://192.168.1.100:5000`

### 4.2 登录

| 字段 | 填什么 |
|------|--------|
| 用户名 | `admin` |
| 密码 | `admin123` |
| 验证码 | 看图片上的字母数字，输入即可 |

点击 **"登录"**。

### 4.3 登录后第一件事

**修改默认密码！**

1. 点击页面右上角的 **管理员**
2. 选择 **"修改密码"**
3. 旧密码：`admin123`
4. 新密码：设一个你自己的（需要大写+小写+数字，至少8位）
5. 确认 → 保存

## 故障排除

### 问题 1：huakey-app 是红色/一直在重启

**原因**：MySQL 还没准备好，应用连不上数据库。

**解决**：
1. 等 1 分钟
2. 在 Container Manager → 容器 → 右键 `huakey-app` → **"重启"**

### 问题 2：提示端口 5000 被占用

**原因**：群晖有其他服务用了 5000 端口。

**解决**：
1. 用 File Station 打开 `huakey-crm/docker-compose.synology.yml`
2. 找到 `ports:` 下面的 `"5000:5000"`
3. 改成 `"8080:5000"`
4. 保存
5. 在 Container Manager → 项目 → 删除项目 → 重新创建
6. 以后用 `http://群晖IP:8080` 访问

### 问题 3：构建失败，提示内存不足

**解决**：
1. 关掉群晖上不用的套件
2. 重启群晖
3. 重新创建项目

### 问题 4：能打开页面但登录报 500 错误

**原因**：数据库初始化不完整。

**解决**：
1. Container Manager → 项目 → 删除项目
2. Container Manager → 存储空间 → 找到 `huakey-crm_mysql-data` → 删除
3. 重新创建项目（会重新初始化数据库）

### 问题 5：忘记密码

**数据库密码**：用 File Station 打开 `huakey-crm/.env` 文件查看

**CRM 管理员密码**：默认是 `admin123`，如果改过忘了，需要重置数据库

## 日常使用

### 多人访问

同一个局域网内，任何人用浏览器打开 `http://群晖IP:5000` 都能使用。

### 手机访问

手机浏览器打开同样的地址即可，界面自动适配。

### 重启系统

Container Manager → 项目 → 选中 `huakey-crm` → 操作 → 重启

### 备份数据

**方法 1（通过 CRM）**：登录 → 系统管理 → 数据备份 → 创建备份

**方法 2（通过群晖）**：
1. Container Manager → 容器 → 停止 `huakey-mysql`
2. File Station → 找到 Docker 数据卷目录
3. 复制 `huakey-crm_mysql-data` 文件夹到安全位置
4. 重新启动 `huakey-mysql`

### 群晖关机/重启

数据不会丢失。群晖重启后容器会自动启动。

## 外网访问（可选）

如果需要在家外面访问：

### 方法 1：QuickConnect（最简单）

1. 群晖 → 控制面板 → QuickConnect → 启用
2. 外网通过 `http://quickconnect.to/你的ID:5000` 访问

### 方法 2：路由器端口转发

1. 登录路由器管理页面
2. 找到"端口转发"/"虚拟服务器"
3. 添加：外部端口 5000 → 内部 IP 群晖IP → 内部端口 5000
4. 通过你的公网 IP:5000 访问

> ⚠️ 外网访问建议：使用强密码、定期更换、考虑 HTTPS。
